Field Guide

HOW TO USE
  1. Choose an effect and settings. For Z/S Shape, fill in Columns and Rows, then preview.
  2. Export .bin saves the file to Downloads/OpenLED.
  3. Copy the file to the controller over USB or upload it to SPIFFS.
  4. Use the provided firmware example for ESP32/WS2812B.

Every RGB controller uses a different format. This app exports a universal raw-RGB (.bin) and a readable (.json) program; your controller needs a small parser for that format.
